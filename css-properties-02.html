1. សេចក្ដីផ្តើមអំពី CSS Properties

CSS Properties គឺជាគុណលក្ខណៈដែលអាចប្រើក្នុង CSS ដើម្បីកំណត់រចនាប័ទ្ម និងរូបរាងរបស់ធាតុ HTML។ ក្នុង CSS, Properties ត្រូវបានប្រើរួមជាមួយតម្លៃ (values) ដើម្បីបញ្ជាក់របៀបដែលធាតុត្រូវបង្ហាញលើគេហទំព័រ។

Syntax មូលដ្ឋាន៖

p { color : blue ; }

💡 គន្លឹះ៖ ដាក់ mouse លើផ្នែកនីមួយៗនៃ Syntax ខាងលើ ដើម្បីមើលការពន្យល់លម្អិត! jedem Syntax block gibt Aufschluss über Selector, Property និង Value។
